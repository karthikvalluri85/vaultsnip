# Getting help

| You want to… | Go to |
|---|---|
| Report a bug | In the app: **Feedback → Something is broken**, or [open a bug report](https://github.com/karthikvalluri85/vaultsnip/issues/new?template=bug_report.yml) |
| Report a replica that looks wrong | **Feedback → The replica looks wrong**, or [open a replica report](https://github.com/karthikvalluri85/vaultsnip/issues/new?template=replica.yml) |
| Report sensitive text that was not masked | **Privately**, see [SECURITY.md](SECURITY.md) |
| Suggest an idea | [Discussions → Ideas](https://github.com/karthikvalluri85/vaultsnip/discussions/categories/ideas) |
| Ask a question | [Discussions → Q&A](https://github.com/karthikvalluri85/vaultsnip/discussions/categories/q-a) |
| No GitHub account | In the app: **Feedback → Email instead** |

VaultSnip is a free, personal open-source project maintained on a best-effort basis.
